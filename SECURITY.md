# Security Policy

## Reporting a vulnerability

If you discover a security vulnerability in Torrin, please report it responsibly.

**Do not open a public issue.**

Email **security@torrin.app** with:

- a description of the vulnerability,
- steps to reproduce,
- an impact assessment.

We'll acknowledge within 48 hours and work with you on a fix before any public disclosure.

## Scope

- This repository (the Torrin services and `shared/` core)
- `ghcr.io/torrin-app/torrin/*` — the published Docker images
- `torrin.app` / `api.torrin.app` — the hosted service and API

## Out of scope

- Third-party services and providers Torrin depends on
- Social engineering
- Denial of service / volumetric attacks
